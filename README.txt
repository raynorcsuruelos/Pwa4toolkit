ANDROID PWA - ORIGINAL PRE-XIAOMI STYLING (v25)

On Android Chrome, extract the ZIP and upload the nine files to the root of your GitHub Pages repository. Do not upload the ZIP itself.
Then open the HTTPS GitHub Pages URL in Chrome and use the menu > Add to Home screen > Install.
Open online once before testing offline.

Important: Back up existing toolkit data first. Browser storage is isolated by site origin; upload/update on the SAME GitHub Pages repository to preserve that origin. Folder access may be limited on Android.
